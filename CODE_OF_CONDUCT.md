# Community Code of Conduct

We aim to keep this project welcoming to everyone, regardless of background, skill level, or identity. Be respectful, constructive, and considerate when discussing issues, reviewing code, or engaging with contributors.

Harassment, threats, discriminatory remarks, and publishing others' private information are not acceptable.

Report concerns privately to the repository maintainers using GitHub's private reporting options once enabled. Maintainers may remove abusive comments or restrict participation to protect the community.
